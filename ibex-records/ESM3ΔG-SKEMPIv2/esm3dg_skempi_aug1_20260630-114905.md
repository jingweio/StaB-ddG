# ESM3ΔG-SKEMPIv2 — experiment record  (created 2026-06-30; status: RUNNING)

## 1. Goal / hypothesis
测试:**MGnify 稳定性预训练(经 ESM3ΔG)+ LoRA 微调,能否直接迁移到 SKEMPI binding ΔΔG**,以及相对 plain-ESM3 是否有提升。
本任务 = "MGnify-pretrained ESM3 + LoRA,SKEMPI-only"(不经 Megascale stage)。与 task2(`ESM3ΔG-Megascale-SKEMPIv2`)配对,共同回答"加 MGnify/Megascale 稳定性知识对 binding ddG 是否有用"。

## 2. Design & decision points  (写于提交前)
- **架构(忠实微调 ESM3ΔG)**:ESM3(冻结)+ LoRA(r=4)+ stability head + SigmoidScaling。binding ddG 用 StaB 分解 `binding_ddG = complex − binder1 − binder2`,每项 `folding_ddG = dG(mut) − dG(wt)`,`folding_dG` = ESM3ΔG stability head 的逐残基 ΔG 在非特殊 token 上的**均值**。
- **纯 LoRA+head 训练**:ESM3 trunk 与 VQ-VAE 结构编码器**全冻结**(按名过滤 + 数据构建后 re-freeze;仅 4,144,131 可训练参数;ckpt ~16.6MB)。
- **结构来源**:SKEMPI 用 StaB `SKEMPIDataset` 解析的 seq + SKEMPI backbone 坐标(atom37)编码进 ESM3 → 保证 WT 序列与 StaB 对齐、结构口径同 ProteinMPNN baseline。
- **KEY DECISIONS(选项 + 理由)**:
  - **模型版本 = `ESM3dG_weights_augmented_1`** —— ESM3ΔG 有 base / augmented 两版(augmented 训练时给 domain 两端加 GS-linker 纠正末端偏差),各有 3 个 ensemble 成员(_1/_2/_3)。**本次用 augmented 的单成员 `_1`(非 3-成员 ensemble)**,理由:先以单卡单成员快速看趋势,省 a100。**⚠ 用户保留最终决策权**:确认有提升后可改用 3-成员 ensemble / 对比 base 版。(用户 2026-06-30 同意本次先 augmented_1。)
  - **超参**:lr 6e-5,AdamW,weight_decay 0.05,epochs 15,seed 0,`--max_batch 4`(OOM 时 M→2→1 重试再跳过)。lr/optimizer/wd 沿用 esm-replace 对 ESM3 调优得到的最优区间。
  - **数据/split**:SKEMPI `filtered_skempi.csv`,train split (`train_pdb.pkl`, 120 complexes / 3050 mutants),test split (`test_pdb.pkl`, 81 complexes)。
- **对标 baselines**:ProteinMPNN(StaB-ddG)per-structure **0.448** / overall 0.531;plain-ESM3(esm-replace, full-FT)SKEMPI-only **0.148**。**本任务直接对比 0.148** → 看 "MGnify 预训练 + LoRA" 是否优于 "plain-ESM3 full-FT"。
- **评测指标**:SKEMPI test 的 **per-structure Spearman**(每复合物内排序的均值)+ overall Spearman。

**结论 / 观察**:
- **严重 train/test 过拟合**:train 0.64 vs test per-structure 0.071。LoRA+head 记住了 train 复合物的突变排序,但**不泛化**到 test 复合物的界面内排序。
- **overall(0.256) ≫ per-structure(0.071)**:模型抓住跨复合物的粗幅值(整体多稳/多不稳),但学不到**界面内精细排序**——而后者才是 binding ddG 的目标指标。怀疑与 `folding_dG` 的**逐残基均值聚合**对大复合物单点突变的 1/L 稀释有关。
- **远低于 ProteinMPNN 0.448**(同 split)。⚠ 与 plain-ESM3 的 0.148/0.242 **不是同一 split**(那是 esm-replace 的 homology-OOD THRESHOLD=10),不能直接比;同 split 的干净对标是 ProteinMPNN 0.448。
- **待办诊断(未自动执行,等用户定)**:① eval `_ep5.pt`/`_ep10.pt` 看是否早停能缓解过拟合(train ep5=0.27/ep10=0.48 → test 可能更高);② 若确认是聚合稀释问题,可试把 `folding_dG` 改 SUM(对齐 StaB)。
