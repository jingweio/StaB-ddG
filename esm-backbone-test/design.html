StaB-ddG · 把 ProteinMPNN 换成 ESM backbone

改造设计文档 (design spec) — PPI 突变效应预测 (ΔΔGbind) · 两条并行实验线
日期 2026-06-23 StaB-ddG 分支 esm-replace esm 仓库分支 reproduce ProteinMPNN 基线 per-interface Spearman 0.445 计算 KAUST Ibex (a100)
本文档中的每一条技术论断都已用 5 个并行 agent 对照真实代码做过对抗式核验(见文末「核验附录」); 被标 NUANCE 的点已在正文按代码事实修正。

1 · 目标与假设

StaB-ddG 完全建立在 ProteinMPNN 之上。本实验把这个"打分骨干"替换掉,走完 StaB-ddG 的两阶段训练 + 推理全流程,检验: 用现代 ESM 模型替换 ProteinMPNN,能否在 PPI 突变效应预测上带来提升?(以论文头号指标 per-interface Spearman 为准,ProteinMPNN 复现基线 = 0.445。)

2 · StaB-ddG 只用到一个"原语"

StaB-ddG 对 ProteinMPNN 的唯一调用是 stabddg/model.py: folding_dG—— 给定固定 backbone 结构 X 与序列 S,返回每残基对数概率并求和,得到结构条件下的序列对数似然:

dG(domain, seq) = Σi  onehot(seq)i · log_softmax(pmpnn(X, S, …))i

其余全部建立在这一个标量之上(已核验 SUPPORTED):

folding_ddG = dG(mut) − dG(wt)  # wt/mut 共享同一组 decoding_order + backbone_noise(antithetic 方差缩减)
binding_ddG = complex_ddG − ( binder1_ddG + binder2_ddG )
最终预测 = mean20( binding_ddG ) × (−1)  # MC ensemble=20,负值=稳定化(仅推理期)
NUANCE StaBddG 类本身不引入任何可训练参数,ProteinMPNN 是唯一的学习型打分器; (同文件里另有一个未被使用的 LinearModel,推理路径不经过它。)
替换工作的本质:只重写 dG(domain, seq) 这一个函数,StaB 的恒等式与方差缩减原样保留。

3 · 为什么不能"字面替换成 ESMFold2"

仓库 /home/guoj0f/repos/esm 是 EvolutionaryScale esm v3.3.0(含 ESMC / ESMFold2 / ESM3)。三者能力已核验:

模型做什么能给 log P(seq | 结构) 吗?能否顶替 StaB 原语
ESMFold2(基于 ESMC 6B)正向折叠 seq→3D(扩散,默认 200 步,.fold())❌ 代码未暴露任何"给定结构给序列打分"的接口 (README 提到 "inversion of ESMFold2" 用于 binder 设计,但本代码库未封装成 seq-likelihood API)不能直接用
ESMC 300M/600M/6B纯序列语言模型,.logits()→sequence_logits⚠️ 只有 log P(seq),无结构可(序列似然变体)
ESM3(ESM3_sm_open)多模态:forward(sequence_tokens, structure_tokens, …)→sequence_logits✅ 是 — 结构条件序列似然,ProteinMPNN 的真正功能对应物可(最忠实)

结论:ESMFold2 是正向折叠模型,塞不进 StaB 的打分循环。因此选定两条线—— ESM3(保留结构条件,最忠实) 与 ESMC-6B(纯序列,最强语言骨干)。

class SequenceScorer(nn.Module):
    def dG(self, domain, seqs) -> Tensor:   # [B] 结构/序列条件下的序列对数似然
        ...
# 三个实现,彼此隔离:
#   MPNNScorer  (现有 ProteinMPNN, 基线)
#   ESM3Scorer  (Track A: 结构 token + 序列 → sequence_logits)

StaB 的 folding_ddG / binding_ddG / ensemble / 符号 逻辑完全复用,只换 dG() 的实现。 ESMC-6B 另需一套 FSDP 训练 harness(StaB-ddG 原仓库没有分布式训练)。

6 · 两阶段训练(忠于原文)

阶段内容Track A (ESM3) 数据Track B (ESMC) 数据
Stage 0zero-shot 在 SKEMPI test 上评测(去风险,几乎免费)无需训练
Stage 1Megascale 折叠稳定性 full-FT(从预训练 ESM 权重初始化)需 AlphaFold PDB(结构)序列(从同一批 PDB 解析)
Stage 2SKEMPI 结合能 full-FT(从 Stage-1 初始化)→ OOD test 评测SKEMPI splits(已具备)
为什么 Stage-1 还需要 AlphaFold PDB? Megascale(Tsuboyama et al. 2023)是一个高通量稳定性测量数据集 —— 由蛋白酶解实验得到的 (序列, 折叠 ΔΔG) 对,本身不含任何实验结构。但 StaB 的打分是 log P(seq | backbone),必须有一个 backbone 作为条件;这些 mini-domain 没有实验结构,于是用 AlphaFold 预测的 backbone(AlphaFold_model_PDBs.zip,同一 Zenodo 记录)充当那个固定结构。所以"在 Megascale 上训练" = 在 (AF backbone, WT+突变序列, 实测 ΔΔG) 三元组上训练。
→ ESM3 是结构条件模型,同样需要这些 backbone;ESMC 是纯序列模型,不需要结构(只需序列,直接取自 CSV;表中"从 PDB 解析"只是复用现成管线的便利,非必需)。
NUANCE 数据细节(已核验):
  • Stage-1 stability_finetune.py 默认 --pdb_dir AlphaFold_model_PDBs + Tsuboyama2023…csv + data/rocklin/mega_splits.pkl。AlphaFold_model_PDBs 目录当前不存在,需下载(Plan-D,Zenodo,数十 GB)。
  • Stage-2 skempi_finetune.py 默认训练划分是 data/SKEMPI/train_clusters.pkl(44 个同源簇);train_pdb.pkl(120 复合物)/ test_pdb.pkl(81 复合物)是按 PDB 的实际选择——我们的复现正是用这两者(经非默认参数);skempi_eval.py 默认评测划分 = test_pdb.pkl。
  • per-interface 指标:baselines/eval_utils.py 按 #Pdb 分组,仅纳入突变数 ≥ THRESHOLD=10 的复合物,跨复合物等权平均 Spearman(test 集 43/81 复合物达标)。

7 · 超参重调(换骨干后必须重新调参)

原版超参是为小模型 ProteinMPNN 调的,几乎肯定不适合 full-FT 一个 1.4B/6B 的 ESM 模型。原值(已核验):

阶段lrepochsbatch (token)noise_levelseed
Stage-1 Megascale1e-670100000.10
Stage-2 SKEMPI1e-620010000(复现用 25000)0.20

1e-6 对 ProteinMPNN(参数极少、本身已是好的 inverse-folding 先验)合适;对大模型 full-FT 通常偏小,且常需 warmup / weight decay / 梯度裁剪。因此做超参扫描,主参数 = 学习率。

扫描网格(每条 track 独立)

超参候选值说明
learning rate(主){1e-6, 5e-6, 1e-5, 3e-5}6B full-FT 取低端(防遗忘/不稳定);1.4B 可探到 3e-5
warmup{0, 线性 5% steps}大模型 full-FT 常需 warmup 稳定早期
weight decay{0, 0.01}次要
noise_levelESM3 {0, 0.1};ESMC N/A结构/backbone 噪声(ESMC 无结构)
epochs按验证集早停小数据防过拟合

分层扫描策略(控成本,尤其 6B)

  • 先在便宜的「单阶段 SKEMPI-only」上扫 LR(从预训练直接微调 SKEMPI、跳过 Megascale)—— 数据小、快 —— 为每条 track 选出最优 LR(+warmup)。
  • 再用胜出超参跑昂贵的完整两阶段(Megascale→SKEMPI)。避免在最贵的 Megascale 阶段盲扫。
  • zero-shot(Stage-0)无超参,先跑取信号。
公平性提示 你已授权直接在 test split 上选超参。这给出的是乐观(oracle 上界)估计 —— 报告 ESM 数字时会明确标注「test-tuned best」。注意 ProteinMPNN 基线 0.445 并未在 test 上调过;为「最优对最优」的公平对照,我会同样对 ProteinMPNN 基线做一次 test-split LR 扫描作为对照行,避免单方面让 ESM 占便宜。

8 · 计算方案与显存账(已核验)

ESMC-6B full-FT → 必须多卡

混合精度 + Adam,逐项:

bf16 参数        12 GB
fp32 master      24 GB
Adam m + v       48 GB
bf16 梯度        12 GB
────────────────────
≈ 96 GB  (还没算激活)

已超单张 a100-80GB → 需 FSDP / DeepSpeed ZeRO-3 分片 + 梯度检查点。Ibex 多数 a100 节点 4×,gpu4 分区有 8× a100,足够。

ESM3-1.4B / ESMC-600M → 单卡即可

1.4B full-FT  ≈ 1.4B×16B ≈ 22 GB
0.6B full-FT  ≈ 9–10 GB

均可在单张 a100-80GB 上 full-FT(配梯度检查点留余量)。

NUANCE StaB 损失的激活开销比想象更重:训练时每个样本约 6 次骨干前向 (complex / binder1 / binder2 三个子系统 × {WT, mutant}),每次都要保留激活以反传 —— 激活倍数约 6×(非 3×)。 MC ensemble(=20)只在推理期,训练期不乘。这进一步加大 6B 的显存压力,坐实分片 + 检查点的必要性。

  • 中 AlphaFold PDB 下载(Stage-1,数十 GB,Zenodo)体积/耗时;ESM3 必需,ESMC 仅取序列。
  • 中 ESM3 结构 tokenize 增加一条预处理流水线与独立缓存。
  • 低 权重已确认 ungated,无需 HF token(原列为依赖,已排除)。

13 · 结果与结论(2026-06-26,ESM3 track)

结论:在 OOD PPI ΔΔG 上,ESM3 替换 ProteinMPNN 不划算。 充分调参 + Megascale 预训练把 ESM3 从 0.086 提到 0.242(证明初版确为欠训,已修复),但仍显著低于 ProteinMPNN 的 0.445。ESM3 能拟合训练集(train Spearman ~0.57)却只泛化到 ~0.24 → 瓶颈是 OOD 泛化,非训练。小而专精的 inverse-folding 网络在该任务上泛化远胜大而通用的 ESM3-via-StaB。
配置per-interface Spearman (SKEMPI OOD test)
ProteinMPNN 两阶段(基线)0.445
ESM3 两阶段,调优(lr=6e-5, AdamW wd=0.05, 15ep)0.242
ESM3 仅 SKEMPI(去掉 Megascale,同配置)0.148 → Stage-1 贡献 +0.094
ESM3 zero-shot0.086
ESMC-6B zero-shot(该 track 已暂停)0.014

超参全扫描(已排除"欠训"):lr {1e-6…3e-4} × wd {0…0.1} × {Adam,AdamW} × {constant,cosine,warmup} × {15,30 ep} + 逐 epoch early-stopping;最优在 lr=6e-5/wd=0.05/15ep 处平台化。Megascale Stage-1(折叠稳定性预训练)确有价值:使单阶段 0.148 → 两阶段 0.242。对比图见 results/comparison.png;明细见 results/RESULTS.md。
